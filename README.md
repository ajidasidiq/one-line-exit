A one-line resignation letter, written to be as funny as one line can be: an office worker who has spent four years answering every email with "per my last email" finally turns the phrase back on the job itself and per-s his last day.

## Run it

```sh
python3 main.py
```

`main.py` writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), deterministically — no input, no randomness, no network. It self-checks the gate first: one line, 1–140 characters, not only whitespace, then reads the file back to verify it byte-exactly.
